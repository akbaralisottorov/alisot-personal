# ALISOT — Akbarali Sottorov

React + Vite asosidagi responsive shaxsiy sayt starter loyihasi.

## Ishga tushirish
1. Node.js 18+ o‘rnating.
2. Terminalda loyiha papkasiga kiring.
3. `npm install`
4. `npm run dev`

Production build:
- `npm run build`
- `npm run preview`

## Tuzilishi
- `src/App.jsx` — sahifalar va interaktiv UI
- `src/styles.css` — dizayn tizimi va responsive stillar
- `public/images/` — sayt rasmlari

## Hozir ishlaydigan qismlar
- Uzbek / Russian / English til almashtirish
- Light / dark rejim
- Mobil menyu va bottom navigation
- Section navigation
- Responsive layout
- Kontakt formasi demo holatida

## Keyingi integratsiyalar
Backend, haqiqiy qidiruv, admin panel, newsletter, izohlar, CV PDF, analitika va AI semantik qidiruv uchun API va ma'lumotlar bazasini ulash kerak.
